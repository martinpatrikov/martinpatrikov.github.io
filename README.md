# Martin Patrikov - Portfolio Website

Portfolio website for Martin Patrikov - Student, Aspiring Quant at Bocconi University.

## Project info

**Website**: https://martinpatrikov.com

## Technologies

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Getting Started

### Prerequisites

- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd martinpatrikov.github.io

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

## Deployment

The site is deployed to GitHub Pages automatically via GitHub Actions on push to the main branch.
